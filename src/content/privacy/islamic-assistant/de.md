# Datenschutzrichtlinie

*Zuletzt aktualisiert: März 2025*

Islamic Assistant ist eine persönliche mobile Anwendung, die Muslimen bei der täglichen islamischen Praxis helfen soll — einschließlich Gebetszeiten, Koranlesung, Dhikr-Zähler und weiteren islamischen Funktionen. Diese Datenschutzrichtlinie erklärt, wie die App mit Ihren Daten umgeht.

## Erhobene Daten

Islamic Assistant erhebt, überträgt oder teilt **keine** personenbezogenen Daten. Alle Daten, die Sie in der App eingeben oder erzeugen (z. B. Dhikr-Zählungen, Lesezeichen oder Einstellungen), werden ausschließlich lokal auf Ihrem Gerät mithilfe von SQLite gespeichert und verlassen Ihr Gerät niemals.

## Berechtigungen

Die App kann folgende Geräteberechtigungen anfordern:

- **Standort** — wird ausschließlich zur Berechnung genauer Gebetszeiten basierend auf Ihrem aktuellen Standort verwendet. Standortdaten werden auf dem Gerät verarbeitet und niemals an einen Server übertragen.
- **Benachrichtigungen** — werden verwendet, um Gebetszeiterinnerungen lokal auf Ihrem Gerät zu liefern.

## Drittanbieterdienste

Islamic Assistant integriert keine Analyse-, Werbe-SDKs oder Tracking-Dienste von Drittanbietern. Es werden keine Daten an externe Parteien weitergegeben.

## Datenspeicherung

Alle App-Daten werden lokal auf Ihrem Gerät mithilfe von SQLite gespeichert. Durch die Deinstallation der App werden alle lokal gespeicherten Daten dauerhaft gelöscht.

## Datenschutz für Kinder

Diese App erfasst wissentlich keine Informationen von Kindern unter 13 Jahren. Da grundsätzlich keine Daten erhoben werden, ist die App für alle Altersgruppen geeignet.

## Änderungen dieser Richtlinie

Wenn diese Datenschutzrichtlinie aktualisiert wird, wird die neue Version unter dieser URL veröffentlicht. Die weitere Nutzung der App nach Änderungen gilt als Zustimmung zur aktualisierten Richtlinie.

## Kontakt

Bei Fragen zu dieser Datenschutzrichtlinie können Sie uns über den Kontaktbereich auf [tursoft.net](https://tursoft.net) erreichen.
