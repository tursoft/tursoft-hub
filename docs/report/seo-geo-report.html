Executive summary

One rich site, almost invisible to search engines and AI systems

The site has rich, well structured content (86 projects, 217 skills, 14 experience entries, 30 customers, 18 references, a complete education history) and a solid llms.txt. Almost none of that reaches search engines or AI assistants today, for three structural reasons.

  1. The HTML shell is empty. The server sends a 2.2 KB document containing only meta tags and an empty root element. All content is injected by an 869 KB JavaScript bundle that then fetches JSON data at runtime. Google can render it, with delay. Bing, social scrapers and every AI fetcher receive a title and a description and nothing else. F-01
  2. Cloudflare is actively blocking AI crawlers. The served robots.txt disallows ClaudeBot, GPTBot, Google-Extended, CCBot, Meta, Amazon, Apple and twenty more agents, and the edge returns HTTP 403 to GPTBot and ClaudeBot even for llms.txt. F-02
  3. There is exactly one indexable URL. Every other path returns HTTP 404, including the AmelBook privacy policy. No sitemap, no structured data, no per-topic pages, no crawlable internal links. F-03

On top of those, several hygiene issues hurt immediately: the Open Graph image returns 404, http:// is not redirected to https://, the www host redirects to the insecure scheme, facts disagree across surfaces (20+ vs 25+ years, Jengai vs Tursoft), and 63 PDF, DOC and ZIP files including old CVs are publicly crawlable.

The five things to do first

  1. Turn off AI bot blocking and the managed robots.txt in Cloudflare (F-02). Zero code, ten minutes, largest GEO impact.
  2. Enable "Always Use HTTPS", HSTS and a www to apex redirect in Cloudflare (F-05).
  3. Ship a real og-image.jpg and fix the meta tags (F-10, F-12).
  4. Add prerendering to the build so every route ships as real HTML with content (F-01, F-03, F-07). This one engineering change unlocks everything else.
  5. Add a sitemap, JSON-LD Person/WebSite/ProfilePage, and register the site in Google Search Console and Bing Webmaster Tools (F-04, F-06, F-16).
